# CommercePulse

End-to-end analytics platform on an e-commerce marketplace dataset:
raw data → cloud lakehouse → SQL models → dashboards.

## Business problem
"An online marketplace needs to understand delivery performance, customer retention, and revenue growth to remain competitive.
About 7% of orders face delivered delays, and customer repeat purchases remain low,
directly impacting customers satisfaction. This project is based on cleanses ans structure data with the goal to show with interactive dashboards."

## Planned stack
Python/Pandas · AWS S3/Glue/Athena · dbt · Airflow · Power BI · GitHub Actions
